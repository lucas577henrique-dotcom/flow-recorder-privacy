# Flow Recorder — Privacy & Data Handling

This public repository hosts the privacy information for **Flow Recorder**, an independently developed Chromium browser extension for documenting browser workflows and generating structured process documentation.

- **Privacy Policy:** [Read the Flow Recorder Privacy Policy](PRIVACY.md)
- **Current documented version:** 45.0.5.4
- **Last updated:** 19 October 2026
- **Source code:** maintained separately in a private repository; it is **not** distributed from this public repository.

## Questions and requests

For general questions about the policy, please use [GitHub Issues](https://github.com/lucas577henrique-dotcom/flow-recorder-privacy/issues). Do **not** post personal or confidential information in public issues.
